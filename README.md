This repository holds my entry for make.fun's bounty `u-mfnakmal-dad-joke-showdown-1d2ce3e5`: a small Python 3.13, standard-library-only program that writes one short dad joke (129 characters, no trailing newline) to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR`, falling back to `/output`, and prints the character count to stderr.

The entry text:

```text
My dad sent his steak back twice. When it finally came he clapped for it. The waiter said, 'Sir, that's not how well done works.'
```

Run it with:

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
